# H-39「治癒者」 / H39-Healer

Minecraft 1.21.1 / NeoForge / Java 21 / TaCZ 1.1.8 Hotfix R7 / Meds and Herbs 1.2.1.

**開發中，尚無可安裝的正式版。**

## 0.1.19-alpha LuaJ 動態測試與多玩家修正
- 使用 TaCZ JAR 內附的 **LuaJ 執行器及原生 default_state_machine.lua** 模擬瞄準、射擊、換彈、跨玩家切槍及 20 發藥管拋出；不是單靠 JSON 或字串掃描測試。
- 已實際重現 0.1.16 的缺陷：多個 H-39 動畫上下文共用 `last_rounds` 導致拋管遺漏；改用以 `context` 為鍵的弱參照表，分別保存彈數與藥管顯示狀態。
- 仍未取得右鍵斷線當時的客戶端例外堆疊；LuaJ 通過不等於已完成 Minecraft 實機驗證。

## 0.1.19-alpha 實機問題修正
- 針對先前回報的「右鍵後斷線」：移除 H-39 Lua 新增的額外動畫狀態，以及對 TaCZ 共用動畫軌道計數的修改；改用既有主狀態與第 5 條平行軌道。這是防範狀態機衝突的修正，仍需客戶端 `latest.log` 驗證真正的斷線原因。
- 針對「子彈亂飛」：全部姿態的 `inaccuracy` 設為 0，去除隨機散布；速度 200、重力 0.03 和醫療效果不變。
- 針對「模型跑到頭上」：將 `idle_view`、`iron_view`、`camera` 等位置依 TaCZ 既有狙擊槍方式建立正確的骨骼關係與視角偏移。
- 原創槍身改為纖細的雙前翼、深色細槍管、縱向綠色藥液視窗與白色醫療護板；補強薄白色側甲與每管獨立的側面綠色液窗，保留四管用盡的可見狀態。設計參考使用者提供的 H-39 概念圖。
- 上述皆屬源碼與模型修正；尚未在實際 Minecraft 中完成驗證，不能宣稱右鍵斷線完全修好。

## 設計規格
- 半自動醫療步槍，180 RPM，4 管醫療藥管，每管 5 發，共 20 發；可逐管補充。採用氣動式單一供彈計數（TaCZ `open_bolt`），避免槍膛額外藏一發造成 HUD 與藥管數不一致。
- 對一般生物：0.5 HP 穿刺、8 HP 即時治療、每秒 2 HP 持續 10 秒；重複命中刷新而不疊加。
- 對不死生物：相同穿刺傷害，另外造成完整 8 HP 即時傷害與每秒 2 HP 持續 10 秒。已處理 TaCZ 初始命中帶來的受傷無敵幀，避免 8 HP 只計入 7.5 HP。
- 清除指定外傷，不清除感染與中毒。
- 醫療藥管配方：蘆薈葉×5、洋甘菊×5、車前草葉×5、玻璃管×2、閃爍西瓜片×5、鐵錠×1。
- 換彈現在由伺服器控管：戰術換彈 2.8 秒、空槍換彈 3.2 秒；實際扣管與補彈在動畫結束後，切槍或死亡會取消。
- 已補上原創氣動射擊／氣閥／換彈 OGG 音效，並獨立建模射完的空醫療藥管。

## 0.1.19-alpha 開發狀態
已加入 H-39 原創槍枝與醫療藥管幾何模型、純 Python 產生的 PNG 貼圖與圖示、使用 ffmpeg 產生的原創 OGG 音效、TaCZ 動畫與 Lua 藥管顯示狀態機；Java 端已註冊 TaCZ 額外槍包匯出 API；建置後額外檢查 JAR 是否真的包含槍身、藥管、動畫、貼圖、音效與完整白名單，預計使用單一 JAR 自動將槍包匯入遊戲目錄。GitHub Actions 已成功執行 NeoForge Gradle 編譯，但尚未實際進入遊戲驗證配件掛載、醫療效果與換彈動畫，因此請勿將此版本當成正式可遊玩版。

H-39 採用**氣動式醫療彈丸**，TaCZ `bullet.speed` 設定為 **200**（低於原生 M4A1 的 270 和 M700 的 380），為補償降速將 `bullet.life` 延長至 **1.5**；因為彈頭是輕型針狀醫療彈，`bullet.gravity` 降至 **0.03**，減少明顯下墜，其他醫療傷害與彈藥規則不變。詳見 [氣動彈道說明](docs/H39_PNEUMATIC_BALLISTICS_zh_TW.md)。

已取消內建 2×／4×／6× 瞄準鏡切換；改由玩家選配 TaCZ 原生瞄具、雷射、前握把及槍口配件。詳見 [配件選配說明](docs/H39_ATTACHMENTS_zh_TW.md)。

槍包詳情請參閱 [gunpack/README.md](gunpack/README.md)；TaCZ 公開 Maven 編譯依賴不包含你的個人修改版，若要用自己的 TaCZ JAR 進行本地編譯，請放到 `libs/tacz.jar`。

新增 H-39 槍枝工坊合成配方（適用 Zone Zero）：鐵錠×32、銅錠×8、紅石粉×8、Zombie Extreme 鋼錠×3、Meds and Herbs 玻璃管×4、KubeJS 瓶蓋盒×4、鑽石×2。詳見 [製作配方](docs/H39_CRAFTING_zh_TW.md)。

空藥管拋出現在只會在真實單發射擊讓彈數從 16→15、11→10、6→5、1→0 時觸發，不會因為遠端彈數同步或管理員變更彈數而意外拋管。醫療藥管也可放在副手欄位，伺服器會一併計數、扣管，避免副手有藥管卻無法完成換彈。醫療持續效果已改成僅追蹤實際命中的目標，避免廢土伺服器每個殭屍每個 Tick 都產生或查詢持續化 NBT；仍保留區塊載入時恢復的醫療效果資料。

已新增 TaCZ 個別配件 ID 白名單，僅提供 7 件已核對的瞄具、雷射指示器、前握把與消音器；不開放擴充彈匣及特殊彈頭。詳見 [選配說明](docs/H39_ATTACHMENTS_zh_TW.md)。

已新增伺服器啟動時的內容診斷，直接查 TaCZ 是否載入 H-39 槍枝、醫療藥管，以及 Meds and Herbs 六種外傷效果；缺漏會寫入伺服器日誌。管理員也可執行 `/h39 check` 再次檢查，完全不修改地圖或物品。詳見 [載入診斷說明](docs/H39_RUNTIME_CHECK_zh_TW.md)。Meds and Herbs 1.2.1 起列為必要前置。

第三方 TaCZ、Meds and Herbs JAR 不會提交到本儲存庫。
伺服器 `/h39 check` 現在也確認槍枝工坊中的 H-39 本體與醫療藥管兩種配方是否被 TaCZ 正確載入，而不只檢查槍／彈藥索引。

TaCZ JAR 交叉比對新增槍枝工坊配方格式檢查與七款指定配件的實際索引檔確認，可在 GitHub Actions 自動辨識已移除或拼錯的配件 ID。

### 換裝新版 H-39 時的槍包快取
關閉客戶端與伺服器後，移除舊的 `h39medical-*.jar`，僅安裝最新同版本 JAR。若 TaCZ 已從先前 JAR 匯出 `tacz/h39_healer`，請先備份並刪除**這個 H-39 專用資料夾**，讓新版本重新匯出模型。**不要刪除 `tacz_default_gun`，也不要替換原本 TaCZ JAR**。

右鍵斷線仍需使用者提供當次**客戶端** `logs/latest.log`、`crash-reports` 或 `disconnect-*.txt` 才能定案，伺服器的 `Connection reset by peer` 不是原因堆疊。

## 0.1.19-alpha｜氣動「碰咻」射擊音效
- 實機已回報：0.1.17-alpha 開火沒有聲音。這次不再依賴 TaCZ 槍包匯出音效是否被 Minecraft 音效資源管理器識別。
- H-39 **獨立註冊 NeoForge 音效事件** `h39medical:pneumatic_shot`，把原創加長 0.48 秒的「碰—咻」OGG 放在模組資源根目錄；TaCZ 伺服器確認 `GunShootEvent` 後，一次射擊僅向附近玩家廣播一次音效，射手本人也能收到。
- 移除 H-39 槍包內舊射擊音效欄位，避免未來 TaCZ 正常載入時雙重播放；原射擊檔仍保留於槍包供其他相容用途。
- 原本的速度 200、重力 0.03、全部姿態隨機散布 0 仍在資料中；不改 TaCZ 原始 JAR。
- 這是透過 API 與檔案驗證的修改，尚未遊戲內測試；外觀、持槍視角及彈道還無法宣告全部完成。

## 0.1.19-alpha｜外觀補強與音效驗證
- 根據原始 H-39 設計圖，槍口上下分叉白色護翼改成分段收尖的陶瓷外殼，減少前版看起來像幾根直桿的問題；中央黑色細槍管、側面綠色藥液窗與紅十字保留。
- 原生 NeoForge `pneumatic_shot` 聲音檔已在實際編譯 JAR 中解包驗證為 **0.48 秒 Vorbis OGG**，平均音量約 -16.4 dB、峰值約 -1.1 dB；`GunShootEvent` 伺服器端觸發，且 `ServerLevel.playSound(null, ...)` 會廣播給包含射手本人的附近客戶端。
- 附加台灣繁體中文的射擊字幕，並加入外形輪廓自動檢查。仍須真正進 Minecraft 驗證聲音、持槍鏡頭與彈道，現在不請使用者提早測試。
