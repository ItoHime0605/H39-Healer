# H-39 TaCZ 槍包開發狀態

目前此目錄仍是槍包骨架；**尚無經完整 TaCZ 驗證的槍枝資料、3D 模型、貼圖、動畫與換彈事件整合**，請勿當成可安裝槍包。

## 已確定的彈藥規格

- 共用彈藥數值：0～20，HUD 僅顯示例如 `10/20`。
- 醫療藥管每管固定補充 5 發；只在至少有 5 發空間時消耗一管。
- 射擊從前方依序消耗；每消耗完整 5 發，對應的前方藥管從槍身模型消失。
- 可見藥管數為 `ceil(剩餘發數 / 5)`，例如 20→4 管、10→2 管、1→1 管、0→0 管。
- 只保存一個剩餘發數，不保存四管獨立狀態。
- `H39AmmoCounter` 和 `H39AmmoState` 是可單獨測試的 Java 邏輯，**目前尚未接到 TaCZ 物品資料與動畫**。
