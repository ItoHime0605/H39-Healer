# H-39 TaCZ 槍包｜0.1.15-alpha

Minecraft 1.21.1／NeoForge／TaCZ 1.1.8 Hotfix R7。

## 本版外觀與瞄準改動
- 模型主體重新設計為細長白色槍體，中央黑色槍管、雙側收尖的前翼與 4 管翠綠色藥液；採用使用者提供的 H-39 概念圖方向。
- `camera`、`idle_view`、`iron_view` 不再是 [0,0,0]；與 TaCZ M700 等原生狙擊槍的視角骨骼做法一致，避免第一人稱顯示跑到頭上或遮擋鏡頭。
- 各種姿態射擊隨機散布設為 0，避免藥針朝準星外亂飛。
- Lua 不再修改 TaCZ 共用軌道數量，改用預留軌道和原生主狀態更新模型。右鍵斷線仍需由客戶端 log 定位原因。

## 已寫入 GitHub 的實際資源

- 原創 H-39 槍身幾何模型，包含槍管、槍托、瞄具安裝導軌、紅十字與四個獨立醫療藥管骨骼。
- 醫療藥管道具的原創 3D 幾何模型。
- TaCZ 格式的射擊、瞄準、換彈、拿出、收起與檢視動畫資料。
- 可用純 Python 3 標準函式庫產生的 UV 貼圖及槍枝／藥管圖示。
- 由原創程式產生的 8 組氣動射擊、低噪音與裝填音效（需 ffmpeg）。
- 專門的空藥管幾何模型與貼圖，每五發用盡才由 TaCZ 的彈殼特效位置拋出。
- 獨立槍包 ZIP 及模組 JAR 內嵌資源的建置腳本。
- 醫療藥管與 H-39 槍枝本體的 TaCZ 槍枝工坊候選合成配方；槍身材料包含 Zone Zero 使用的瓶蓋盒與 Zombie Extreme 鋼錠。

相關配置與合成材料請參閱 [選配說明](../docs/H39_ATTACHMENTS_zh_TW.md)及 [製作配方](../docs/H39_CRAFTING_zh_TW.md)。

### 自動產生圖片與槍包

在專案根目錄執行：

```bash
python3 tools/generate_h39_gunpack.py --zip dist/H39-Healer-Gunpack.zip
```

GitHub Actions 的 `build-mod.yml` 會先跑檢查，再嘗試完整 NeoForge 21.1／Java 21 編譯。
資源會打包於 JAR 的 `assets/tacz/custom/h39_healer/`，另外產出可獨立安裝的槍包 ZIP。

## 已確定的規格

- 共用彈藥計數 0～20；HUD 目標是 `10/20`。已將供彈動作改為 TaCZ `open_bolt`，不再建立另一顆獨立的槍膛彈，避免實際射擊時出現彈數錯亂。
- 醫療藥管每管補充 5 發；只在至少有 5 發空間時消耗一管。支援背包與副手欄位中的醫療藥管。
- 可見藥管數 `ceil(剩餘發數/5)`；只有單次減少一發、跨過五發邊界才拋出一管，避免重新連線或伺服器同步變動造成錯誤拋管。
- 一般生物：先由 TaCZ 造成 0.5 HP 穿刺，存活才治療 8 HP，並於 10 秒內每秒回復 2 HP。
- 不死生物：轉為即時與持續傷害；不清除中毒或感染。命中追加的 8 HP 應是完整傷害，不被 TaCZ 先前 0.5 HP 的受傷無敵幀減少。
- 氣動式藥管飛行速度 `bullet.speed=200`（低於原本 310）；`bullet.life=1.5` 保持中遠距離支援用途；針狀醫療彈重力由 `0.15` 降為 `0.03`，下墜更小。
- 不再內建倍率切換，開放 TaCZ 的 `scope`、`laser`、`grip`、`muzzle` 選配類型，並新增 `data/h39/tacz_tags/attachments/allow_attachments/h39.json`，只列出 7 件實際存在的推薦配件 ID；不開放擴充彈匣或特殊彈頭。

## 尚未完成／不得宣稱完成

**不可視為可安裝槍包或正式版。**

目前原創模型、貼圖與動畫已有來源及產生方式，**但藥管骨骼目前已透過 TaCZ Lua 狀態機與 0～4 管縮放動畫連接，即時讀取 `context:getAmmoCount()`；但尚未經遊戲內實測。已寫入每第五發拋出空醫療藥管的 Lua 判定；但整個狀態機尚待遊戲內驗證，換彈動畫同步亦尚未實測。內建倍率切換已依需求取消，改為配件自由選擇**。
換彈已改為伺服器定時處理，空槍需 3.2 秒、戰術換彈需 2.8 秒，動畫結束才扣除醫療藥管並補充彈數。切槍、死亡、離開世界會取消。程式已提交並加入測試，仍須進行遊戲內驗證；不能以純邏輯測試取代實測。
模組主類別已呼叫 TaCZ 官方提供的 `ResourceManager.registerExportResource`，將 JAR 的 `/assets/tacz/custom/h39_healer` 登記成額外槍包來源；TaCZ 的 `GunPackLoader` 會於首次載入將其匯出至遊戲目錄下 `tacz/h39_healer`，然後掃描。這條整合路徑已由 TaCZ R7 位元碼核對，但仍需實際遊戲驗證。若玩家在 TaCZ 設定啟用了覆寫／禁止初次匯出選項，則可能需要使用獨立槍包 ZIP。

伺服器首次啟動後，H-39 自動讀取 TaCZ 即時註冊資料確認 `h39:h39` 與 `h39:medical_tube` 已載入，並檢查 Meds and Herbs 的六種外傷效果。缺漏會在伺服器日誌中印出 `[H-39] 缺少：`，協助定位「編譯成功但遊戲找不到槍」的問題。OP 可以使用 `/h39 check` 在遊戲內直接重新檢查。

所有第三方 TaCZ 與 Meds and Herbs JAR 均不會被上傳到公開 GitHub。
