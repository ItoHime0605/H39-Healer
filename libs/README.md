# Third-party build dependencies

TaCZ and Meds and Herbs are third-party mods and are **not** committed to this repository.

For local builds, place a legally obtained TaCZ 1.21.1 NeoForge 1.1.8 JAR at `libs/tacz.jar`.
The full NeoForge build is not yet verified; the separate Java 21 pulse tests can run without mod dependencies.
