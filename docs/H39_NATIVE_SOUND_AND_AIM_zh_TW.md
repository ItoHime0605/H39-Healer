# H-39｜0.1.20-alpha 氣壓槍音效與視角校正

## 射擊音效：不再只靠 TaCZ 槍包

先前 H-39 的 `h39_shoot.ogg` 有實際存在於 TaCZ 嵌入槍包內，但使用者回報開槍完全沒有聲音。TaCZ 的 `SoundPlayManager` 會先檢查 `tacz_sounds/<id>.ogg` 是否在客戶端**作用中的資源管理器**可讀；壓縮檔有該檔案不代表此處必然找到。

新版將原創 0.48 秒「碰—咻」音效直接置於 NeoForge 模組的 `assets/h39medical/sounds/pneumatic_shot.ogg`，由 `assets/h39medical/sounds.json` 定義 `h39medical:pneumatic_shot`，並註冊 `SoundEvent`。TaCZ **伺服器端** `GunShootEvent` 確認 H-39 發射後，使用 `ServerLevel.playSound(null, ...)` 向附近所有玩家播放，包含射手本人。TaCZ 槍包原本的射擊音效欄位已刪除，避免未來雙重播放。

已透過 JAR 解包與 ffprobe 驗證真正產出的音效檔長度 0.48 秒，平均約 -16.4 dB、最大約 -1.1 dB；GitHub Actions 檢查完整 JAR 音效資源路徑及測試音訊能量。本次仍無實際 Minecraft 客戶端測試，所以不能承諾一定聽得到。

## 瞄準位置：用 TaCZ 原生狙擊槍基準校對

玩家提供的 TaCZ R7 中，M700 的 `muzzle_pos=[0,7.25,-24]`、`iron_view=[0,8.40625,16]`。H-39 的 `muzzle_pos` 在 `[0,7.65,-44]`，所以以相近的鏡頭高度差，將 `iron_view` 調成 `[0,8.8,16]`；原先 10.95 過高。空手持槍的 `idle_view` 調為 `[3.1,10.95,16]`，`camera` 調為 `[3.1,10.15,16]`。

本次不修改 TaCZ 原始 JAR、不改其它槍械，也不增加左手顯示。醫療彈飛行速度 200、重力 0.03、各姿態隨機散布 0 未變。
