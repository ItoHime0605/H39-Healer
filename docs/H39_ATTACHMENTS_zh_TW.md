# H-39「治癒者」選配系統

適用 Minecraft 1.21.1、NeoForge、TaCZ 1.1.8 Hotfix R7。

## 本次已確定的決定

H-39 **不再內建倍率切換功能**。槍枝本身只保留上方瞄具導軌與原生不放大的機械瞄準模式（`iron_zoom = 1.0`）。玩家透過 TaCZ 槍枝工坊選配現有瞄具；選配後的放大倍數完全依該瞄具本身的設定決定。

已移除原本的 `h39:healer_optic` 自製多倍率瞄具，並從槍枝 3D 模型移除固定瞄準鏡本體。上方的 `scope_pos` 配件安裝點保留，另新增 `grip_pos`、`laser_pos`；`muzzle_pos` 已存在。

## 推薦選配

這些配件 **全部已從使用者提供的 TaCZ 1.1.8 Hotfix R7 JAR 驗證為實際存在的 ID**，不需要另外安裝配件模組。

| 用途 | 實際 TaCZ 配件 ID | 原版設定效果及理由 |
|---|---|---|
| 近距離救援 | `tacz:sight_srs_02` | 1.5 倍固定瞄具；觀察近距離隊友，瞄準速度較快 |
| 一般中距離支援 | `tacz:scope_acog_ta31` | 2.5 倍固定瞄具；適合主要的中距離醫療狙擊 |
| 中遠距離支援 | `tacz:scope_qmk152` | 3 倍固定瞄具，提供較細的目標觀察能力 |
| 遠距離定點支援 | `tacz:scope_1873_6x` | 6 倍固定瞄具；適合遠距離精準命中，但開鏡較慢 |
| 近距離雷射指示 | `tacz:laser_compact` | 小型雷射指示器，減少不瞄準時的散布、重量小 |
| 操控前握把 | `tacz:grip_magpul_afg_2` | 小幅改善瞄準速度；由於 H-39 原本無後座力，其減後座屬性不會額外帶來意義 |
| 安靜救援 | `tacz:muzzle_silencer_phantom_s1` | 消音器，降低射擊暴露；原版另有些許射速懲罰，玩家自行取捨 |

**主要推薦搭配**：`scope_acog_ta31`（2.5 倍）＋`laser_compact` ＋`grip_magpul_afg_2`；需要隱蔽時選配 `muzzle_silencer_phantom_s1`。

### 不開放的類型

- 擴充彈匣 `extended_mag`／`light_extended_mag`：H-39 固定 20 發與四管×5 發，不能破壞容量。
- 特殊彈頭 `ammo_mod`：醫療藥管是專用彈藥，不能改成一般穿甲、爆裂、燃燒等模式。
- 槍托 `stock`：已使用原創醫療槍托，沒有必要。
- 固定的內建 2×／4×／6× 切換：已取消。

### 實際白名單已實作

TaCZ 槍枝的 `allow_attachment_types` 是類型白名單。這次另外建立了 `gunpack/data/h39/tacz_tags/attachments/allow_attachments/h39.json`，參照使用者提供的 TaCZ R7 原生槍包相同的 `tacz_tags/attachments/allow_attachments` 路徑，**直接列出上表七個配件 ID**。兩道條件共同限制選配種類；不包含擴充彈匣、特殊彈頭或額外槍托。

此項已經進入槍包資料與自動測試，但 **仍需要實際遊戲內驗證 TaCZ 是否正確套用 H-39 自訂命名空間的白名單，才能宣稱選單完全僅有這七件配件**。

本次取消的是 **H-39 自身的倍率切換**。玩家若自行安裝原本就有多倍率功能的其他 TaCZ 瞄具，其倍率行為仍取決於 TaCZ 的原生瞄具，不由 H-39 額外控制。

## 不受選配影響的既定機制

- 一管醫療藥管補充 5 發，最多 20 發。
- 每第五發用盡後才拋出空藥管，不拋一般彈殼。
- H-39 原始無後座力、無距離傷害衰減。
- 一般生物治療、不死生物承受轉換傷害，保留先前確定的醫療效果。
- 如玩家安裝 TaCZ 消音器，消音器自身的副作用依 TaCZ 原始資料處理；不得修改醫療彈藥用途或 20 發容量。
