# H-39 0.1.15-alpha｜第一人稱、射擊與右鍵問題修正

## 本次實測回報

使用者在 Minecraft 1.21.1 NeoForge / TaCZ 1.1.8 Hotfix R7 中回報：

- 枪身過厚，外觀與原先細長的白色醫療狙擊槍概念圖不同。
- 第一人稱槍身出現在畫面頂部或頭頂，嚴重遮擋畫面。
- 射出的醫療針狀彈頭偏離準星，需多次射擊才有一發接近中心。
- 使用 H-39 右鍵時客戶端斷線。

## 已確認問題與修改

1. **視角骨骼**：原模型 `idle_view`、`iron_view`、`camera` 的 pivot 都是 [0,0,0]，而 TaCZ 原生 M700 等槍械在槍膛後方及機匣上方建立視角定位。現新增 `views` 父骨骼，設定 `idle_view=[3.1,11.25,16.5]`、`iron_view=[0,10.95,16]` 和 `camera=[3.1,11.25,16.5]`，並修正持槍手部骨骼。
2. **槍身模型**：改成細薄深色機匣、長型細槍管、白色左右分叉尖翼，槍尾具紅色醫療十字，4 管翠綠藥液沿槍身縱向排列，保留可選配瞄具的導軌。
3. **射擊散布**：原本 stand=5.5、move=6、sneak=3、lie=2、aim=0.05，現全部設為 0；保留彈速 200 與重力 0.03，減少隨機偏離。彈頭仍需時間飛行，不等於命中掃描式 hitscan。
4. **Lua 輸入與狀態機**：原本增加一個 `tube_state` 狀態，並直接變動共用 `default.static_track_top.value`。改由 TaCZ 原本存在的 `base_track_state` 更新藥管顯示，使用原本預留的 `PARALLEL_TRACK_5`，減少與瞄準輸入狀態機衝突的可能。

## 右鍵斷線的證據界線

伺服器紀錄只有 Netty `Connection reset by peer` 和玩家離開資訊，未提供客戶端的例外堆疊。上述 Lua 變更只能視為預防性相容性修正，**不能僅憑伺服器紀錄宣稱斷線已完全修復**。

若仍斷線，請提供客戶端 `logs/latest.log` 在右鍵當下前後的錯誤、`crash-reports` 最新報告，或 `disconnect-*.txt`。不需要重傳 TaCZ，也不需要修改其他槍械。
