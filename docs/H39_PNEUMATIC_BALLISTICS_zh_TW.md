# H-39 氣動式醫療彈｜彈道設定

Minecraft 1.21.1／NeoForge／TaCZ 1.1.8 Hotfix R7

## 設計定位

H-39 不是火藥推進的狙擊步槍，而是**氣動式醫療藥管發射器**。因此飛行速度比一般步槍子彈慢，能讓玩家觀察、預判移動中隊友的走位，但不會慢得像榴彈。

我以使用者提供的修改版 TaCZ Hotfix R7 JAR 內建槍械資料為基準：

| 槍械 | 原生 `bullet.speed` |
|---|---:|
| H-39「治癒者」（本模組）| **200** |
| TaCZ M4A1 | 270 |
| TaCZ M700 狙擊槍 | 380 |

H-39 比 M4A1 慢約 **26%**，比 M700 慢約 **47%**。針狀醫療彈保留較慢的飛行速度，透過低重力設定使路徑較平直。之前 H-39 設定的 310 反而接近一般步槍，已降低。

## 修改的 JSON 欄位

檔案：`gunpack/data/h39/data/guns/h39_data.json`

```json
"bullet": {
  "speed": 200,
  "life": 1.5,
  "gravity": 0.03
}
```

- **speed 200**：降低發射速度，呈現氣動式藥管彈道。
- **life 1.5**：同步增加彈丸存續時間（舊值 0.8），避免減速後有效飛行距離意外縮短。存續時間不是無限射程承諾。
- **gravity 0.03**：從 0.15 降低 80%，保留些微彈道弧度，但不應出現明顯下墜。這是符合輕型針狀醫療彈玩法的遊戲平衡設定，不代表質量越輕就會因重力而下墜越少。
- **傷害衰減**：沿用先前設定，不因這次降低飛行速度而調整醫療彈命中效果。
- **發射速率／傷害／彈藥**：仍是 180 RPM、先造成 0.5 HP 的命中傷害、每管 5 發／總計 20 發；沒有更動。

### 想再調快或調慢

只需編輯 `bullet.speed`，數字越大越快。建議參考範圍：

- `180`：更明顯的氣動式彈道，移動目標需要更多提前量。
- `200`：目前預設，兼顧氣動質感與中遠距離治療用途。
- `220`：偏向快速氣動發射器，仍慢於 M4A1。

由於 H-39 使用 TaCZ 額外槍包匯出機制，可以在匯出的 `tacz/h39_healer` 槍包中編輯此設定；更新槍包或刪除匯出目錄時可能覆寫自訂值，務必自行備份。

**驗證邊界**：`speed`、`life`、`gravity` 欄位已與 TaCZ R7 內建槍枝對照；上述相對數值已核對，但子彈飛行曲線、目標命中時間和伺服器同步仍需遊戲內實測。
