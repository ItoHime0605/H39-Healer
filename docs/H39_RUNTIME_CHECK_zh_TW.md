# H-39 伺服器載入診斷

此功能從 H-39 `0.1.12-alpha` 起提供，適用 Minecraft 1.21.1／NeoForge／TaCZ 1.1.8 Hotfix R7。

## 自動檢查

伺服器啟動完成時，模組會直接向 **TaCZ 的執行中槍枝與彈藥索引**查詢：

- `h39:h39` 醫療步槍
- `h39:medical_tube` 醫療藥管

另外也會檢查 Meds and Herbs 是否存在，以及出血、內出血、失血、骨折、撕裂傷、燒傷這六種效果的註冊狀態。若有缺漏，會以 `[H-39] 缺少：...` 在伺服器日誌中說明。

## 管理員指令

在伺服器控制台輸入 `h39 check`，或管理員在遊戲內輸入：

```text
/h39 check
```

這個指令需要 OP 權限等級 2，只讀取即時註冊資料，不會更改玩家物品、背包、世界或模組設定。可以在首次裝好 H-39、重新啟動後使用。

## 範圍與限制

指令通過僅能證實 **伺服器端**已載入 TaCZ 槍枝、專用藥管與外傷效果；**不代表**客戶端 3D 模型、Lua 動畫、換彈同步或醫療射擊已經遊戲內實測正常。若只看到這項檢查通過，仍不能把開發版當作正式完成。

H-39 現在將 Meds and Herbs 1.2.1 以上版本列為必要前置；原本提供的 `meds_and_herbs-1.2.1` 適用。
